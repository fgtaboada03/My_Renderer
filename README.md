# My_Renderer

A work-in-progress OpenGL renderer with mesh loading functionality, built in C++.

## Overview

This project is a custom rendering engine built from the ground up to explore
real-time graphics programming with OpenGL. It currently supports audio-reactive
visuals, with active development focused on expanding asset and mesh support.

## Features

- Real-time OpenGL rendering pipeline
- In-progress Audio-reactive visualization
- In-progress mesh loading and asset pipeline

## Roadmap
- [ ]  Audio Visualizer
- [ ] `.dds` (texture) file support
- [ ] `.tga` (image) file support
- [ ] `.obj` (3D mesh) file support *(currently buggy, in progress)*

## Tech Stack

- **Language:** C++
- **Graphics API:** OpenGL

## Project Structure

- `AudioVisualizer/` — core renderer and application logic
- `AudioVisualizerTest/` — test project
